Shared planning, practice and development materials for Blue Impulse.

ROVERLAB connects Chapter 2 — Behaviorism & Behaviorist AI, Chapter 3 — Hardware, Chapter 4 — Networking and Chapter 5 — Applications. The seven-stage game uses the player's selected components, network links and rules to determine mission events and results. Vercel serves the static application from `apps/roverlab/public/` on the Hobby plan; GitHub `main` is its production source.

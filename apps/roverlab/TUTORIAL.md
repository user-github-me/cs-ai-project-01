# ROVERLAB — Quick-start tutorial

**Build it. Connect it. Train it. Send it on a mission.**

A 5–10 minute game by Blue Impulse: build a robot, connect its network and teach it IF–THEN responses. Learn how hardware, networking and behaviour work together.

**Play:** https://roverlab-blue-impulse.vercel.app

**Submit or print:** [One-page tutorial PDF](BlueImpulse_ROVERLAB_Quick_Start.pdf)

> **Access from China: connect to your VPN before opening the game.** A VPN is needed on our university network to access the hosted game. No game account or installation is required.

## Your first mission

1. **Choose:** click **Start new mission**, select **Exploration rover**, then **Build this machine**.
2. **Build:** click **Try a starter build**. Inspect the processor, sensors, motors and battery, then select **Connect your robot**.
3. **Connect:** select **Radio**. Connect **Your robot** to **Base station** using Radio, click **+ Connect nodes**, then **Test network connection**. Continue with **Train your robot**.
4. **Train:** use **+ Add training rule** to add these three rules:

| IF | THEN |
| --- | --- |
| Obstacle detected | Stop, then turn |
| Destination reached | Return to base |
| Low battery | Return to base |

5. **Test:** click **Test stimulus & response**. Give a useful response positive feedback, or edit a poor rule.
6. **Launch:** select **Choose a mission**, use **Into the unknown**, and check for **All systems ready**. Fix any listed issue, then click **Launch mission**.
7. **Review:** watch the rover avoid obstacles, visit the research site, report to base and return. Pause or step through the simulation and read the event log, then open **View mission report**. Change one choice and try again.

**Remember:** progress saves in the same browser when storage is available; use **Continue building** to resume. Training uses player-written stimulus–response rules and feedback. Study-guide connections: Chapter 2 — Behaviorism & Behaviorist AI; Chapter 3 — Hardware; Chapter 4 — Networking.

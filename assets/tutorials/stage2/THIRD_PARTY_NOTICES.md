# Blue Impulse — Tutorial output attribution

The revised tutorials use the shared Blue Impulse chapter content and original AI-assisted teaching examples. The full Study Guide and Markdown references identify supporting sources including Sutton and Barto, Nand to Tetris, the IETF, NIST and Unicode. The fictional Pip scenarios, diagrams, worked examples, narration scripts and procedural sound design were developed for this project with Neogpt/Codex assistance.

- **Inter:** copyright The Inter Project Authors; SIL Open Font License 1.1. The document font is embedded as a subset. The full license is in [Inter-OFL.txt](Inter-OFL.txt).
- **Synthetic narration:** Kokoro ONNX, voice `am_michael`, speed 0.92. This is generated English speech, not a recording of a student. [Kokoro model](https://huggingface.co/hexgrad/Kokoro-82M): Apache 2.0. [Inference wrapper](https://github.com/thewh1teagle/kokoro-onnx): MIT. Model and engine binaries are not part of this output collection.
- **Score and sound effects:** original procedural audio created for the tutorials; no third-party song or sampled recording is included.
- **Animation references:** the user supplied [reference 1](https://vt.tiktok.com/ZSp6BC9W5/) and [reference 2](https://vt.tiktok.com/ZSp6S8pAo/) as inspiration for general motion-design techniques. Reference clips are not redistributed.

The output collection contains the final MP4s, captions, tutorial documents, scripts and learning examples. Production code and intermediate renders are retained locally rather than required for the professor to view the lessons.

3.1 Processing Architectures & CPU Design
The Central Processing Unit (CPU) is the computational core of a computer system. Its main role is to execute
program instructions stored in memory by performing Fetch-Decode-Execute cycles. Computer architecture
design dictates how efficiently instructions are processed and how hardware components communicate.
RISC vs. CISC Architectures
Processor instruction set architectures (ISAs) fall primarily into two design philosophies:
CISC (Complex Instruction Set Computer): Designed to execute complex tasks in as few assembly lines as
possible. CISC processors (like x86 architecture found in modern PCs) feature variable-length instructions
and complex hardware decoding circuits. A single CISC instruction might perform a memory load,
arithmetic operation, and memory store simultaneously.
RISC (Reduced Instruction Set Computer): Designed with a small set of simple, fixed-length instructions
that each execute in a single clock cycle. RISC architectures (like ARM processors found in mobile devices
and modern supercomputers) use a load/store architecture where arithmetic operations occur strictly
between internal registers.

Pipeline Hazards: Pipelining can stall due to hazards:
Data Hazard: An instruction depends on the unwritten result of a preceding instruction.
Control Hazard: Branch instructions (e.g., conditional jumps) alter the execution flow, requiring pipeline
flushing.
Structural Hazard: Two instructions require the same hardware resource simultaneously.

Core CPU Registers: High-speed internal memory locations used during processing:
Program Counter (PC): Holds the memory address of the next instruction to be fetched.
Memory Address Register (MAR): Holds the RAM address currently being read from or written to.
Memory Data Register (MDR): Stores data read from or waiting to be written to memory.
Current Instruction Register (CIR): Holds the instruction currently being decoded and executed.
Accumulator (ACC): Temporarily holds intermediate arithmetic and logic results from the ALU.

Supercomputers, Clusters, and Massively Parallel Processing
When processing demands exceed a single machine's capability, specialized high-performance computing
structures are used:
Clusters: A collection of standalone computers (nodes) connected via high-speed local area networks,
operating together as a unified resource. Nodes frequently employ SIMD or multi-core MIMD units.
Supercomputers: Custom-built mainframes housing tens of thousands of processing cores sharing fast
interconnects and memory pipelines, optimized for heavy scientific modeling.
Massively Parallel Computers (MPP): Systems linking thousands of independent processors, each with its
own memory, running programs concurrently via coordinated message-passing interfaces.
Interrupt Handling Mechanisms
An Interrupt is a signal generated by hardware or software requiring immediate CPU attention, pausing
current program execution.

Handling Process:
1. CPU completes current instruction cycle.
2. Contents of registers (PC, ACC, CIR) are pushed onto a memory stack.
3. Interrupt Service Routine (ISR) address is loaded into PC to manage the event.
4. Once resolved, saved register states are restored from stack and normal execution resumes.
CISC vs. RISC Handling: CISC checks for interrupts between complex instruction cycles or multi-cycle steps,
requiring large context saves. RISC handles interrupts swiftly due to uniform single-cycle instructions and
fast register swapping.
Artificial Intelligence Hardware
Modern AI workloads (such as neural network training and inference) require massive linear algebra and
matrix multiplication operations.
Graphics Processing Units (GPUs): Specialized SIMD processors containing thousands of small efficiency
cores designed to execute high-throughput mathematical operations in parallel.
Dedicated AI Accelerators (TPUs/NPUs): Purpose-built integrated circuits tailored for low-precision tensor
operations, maximizing power efficiency for deep learning models.
3.2 Primary Memory & Storage Technologies
Computer storage is structured hierarchically based on access speed, cost, capacity, and volatility. Storage is
broadly divided into Primary Storage (directly accessible by the CPU) and Secondary Storage (non-volatile
retention media).
Primary Storage: RAM vs. ROM
Primary memory communicates directly with the CPU over the system bus.
Random Access Memory (RAM): Read-write, volatile primary memory that temporarily holds operating
system files, active programs, and working data. Data is lost immediately when power supply ceases.
Read-Only Memory (ROM): Non-volatile memory containing critical bootstrap instructions (BIOS/UEFI
firmware) required to boot the system. It can be read from, but not easily written to during standard
operation.

Read-Only Memory (ROM) Evolution
Standard ROM: Pre-programmed during chip manufacturing with permanent binary masks; contents can
never be changed.
PROM (Programmable ROM): Manufactured blank. Can be programmed once by burning internal
microscopic fuses using a high-voltage programmer.
EPROM (Erasable Programmable ROM): Contains a transparent quartz window. Exposure to strong
ultraviolet (UV) light clears all memory cells, allowing reprogramming.
EEPROM (Electronically Erasable PROM): Contents erased and rewritten electronically using pulsed
voltages without physical removal from the circuit board.
Flash Memory: A specialized high-density form of EEPROM that reads/writes data in blocks, forming the
foundation of modern solid-state storage.
Secondary Storage Media Categories
Secondary storage is non-volatile media used to store programs and user files permanently.
1. MAGNETIC STORAGE (HDDS)
Uses spinning magnetic platters read by electromagnetic heads.
• Latency: Rotational delay waiting for disk sector to pass under the head.
• Fragmentation: File sectors scattered in non-consecutive locations degrade read speeds.
• Removable HDDs: Portable external drives connected via USB for backups.
2. SOLID-STATE STORAGE (SSDS)
Uses NAND flash memory cells with floating-gate transistors.
• No Moving Parts: Zero latency, shock-resistant, highly durable.
• High Performance: Extremely fast read/write throughput via electronic grid access.
3. OPTICAL STORAGE (CDS, DVDS, BLU-RAY™)
Reads data using laser light reflected off reflective pits and lands stamped into polycarbonate discs.
• Dual Layering: DVDs and Blu-rays stack two reflective layers, nearly doubling storage capacity.
• Birefringence: A reading error where laser light refracts into two distinct beams inside imperfect disc substrate
materials, causing data corruption.

3.3 Input, Output, Monitoring & Control Systems
Computer systems interact with the physical world through input devices, output devices, sensors, and
actuators. Processing real-world phenomena requires translating continuous physical signals into discrete
digital representations.
Signal Conversion: ADC and DAC
ADC (Analogue-to-Digital Converter): Converts continuous physical signals (e.g., voltage, sound waves,
temperature readings) into digital binary values understood by the CPU.
DAC (Digital-to-Analogue Converter): Converts digital binary output values back into continuous electrical
currents to drive physical actuators, motors, or speakers.
Sensors, Actuators, and Control Feedback Loops
Sensors (Input Devices): Measure physical conditions (e.g., temperature, light level, pressure, humidity,
motion, pH). They produce analogue signals sent to ADCs.
Actuators (Output Devices): Electromechanical devices (e.g., motors, valves, relays, solenoids) that
execute physical movement based on DAC control signals.
Monitoring System: Reads sensor data continuously to display or log environment metrics without
altering the environment directly.
Control System: Reads sensor data, processes it against predefined threshold rules, and uses feedback
loops to drive actuators to alter the environment.

Display Technologies & Advanced Peripherals
OLED (Organic LED): Uses organic compounds that emit light when electric current passes through.
Generates its own light, eliminating backlighting for true blacks, thinner screens, and higher energy
efficiency.
Screen Resolution: Number of distinct horizontal and vertical pixels (e.g., 1920 × 1080) displaying images.
Virtual Reality (VR) Headset: Head-mounted apparatus featuring two separate displays, lenses, and
motion sensors to totally immerse users in virtual surroundings.
3D Printing Technologies:
• Direct 3D Printing: Print head moves along X, Y, and Z axes ejecting melted polymer layers through nozzles.
• Binder 3D Printing: Two-pass method using dry powder spread across a bed followed by a liquid binder
spray.
Embedded Systems and Microcontrollers
An Embedded System is a specialized computer built into a larger machine to perform a specific dedicated
control function (e.g., washing machine controller, ABS brake module). They typically use a Microcontroller—
an integrated IC combining CPU core, RAM, ROM, and I/O ports on a single chip.
Benefits: Compact size, low power consumption, low per-unit cost, high operational reliability.
Drawbacks: Difficult to upgrade, specialized repair required, limited processing capacity.

Boolean Algebra Simplification Laws
Boolean expressions describe logic circuits mathematically and can be simplified using formal laws:
Identity Laws: A · 1 = A | A + 0 = A
Null Laws: A · 0 = 0 | A + 1 = 1
Idempotent Laws: A · A = A | A + A = A
Inverse Laws: A · Ā = 0 | A + Ā = 1
Double Negation: Ā̄ = A
De Morgan's Laws:
• Break the line, change the sign: A · B = Ā + B̄
• A + B = Ā · B̄
WORKED SIMPLIFICATION EXAMPLE
Simplify the Boolean Expression: X = A · B + A · B̄
1. Factor out term A using Distributive Law: X = A · (B + B̄)
2. Apply Inverse Law (B + B̄ = 1): X = A · (1)
3. Apply Identity Law: X = A

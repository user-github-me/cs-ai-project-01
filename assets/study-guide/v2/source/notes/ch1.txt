1.1 Number Systems & Data Representation
Computers consist of millions of tiny transistors acting as electronic switches that are either ON (1) or OFF (0).
Because of this, computers naturally speak Binary (Base-2).

Signed Binary Representation
To represent negative numbers, we use three distinct techniques:
1. Sign & Magnitude: Most Significant Bit (MSB) denotes sign (0 = +, 1 = -). E.g., 10000101 = -5.
2. One's Complement: Flip all bits of the positive number (05 = 00000101 → 11111010 = -5).
3. Two's Complement: Flip all bits and add 1 to the right-most bit. E.g., +5 (00000101) → Flip (11111010) → Add
1 = 11111011 (-5). Range for 8 bits: -128 to +127.
Hexadecimal & Binary Coded Decimal (BCD)
Hexadecimal (Base-16) makes long binary strings human-friendly (e.g., HTML color #FF0000, MAC addresses,
and Memory Dumps during error debugging). Each Hex digit represents exactly 4 bits (a nibble).
Binary Coded Decimal (BCD) encodes each individual denary digit (0–9) using 4 bits. For instance, denary 798
becomes 0111 1001 1000. BCD is widely used in financial hardware (calculators, digital clocks) to avoid
rounding errors.

Sound Representation
Sound is analogue continuous audio waves. Computers convert it into digital data via an ADC (Analogue-to-
Digital Converter) using two key settings:
Sampling Rate: Number of sound samples taken per second (Hz). Higher rate = closer match to original sound
wave.
Sampling Resolution: Number of bits allocated per sample. Higher resolution = greater dynamic range and
accuracy, but larger file size.
Compression Methods
Lossy Compression: Removes unnoticeable data permanently (e.g., MP3 audio, JPEG images). Reduces file size
drastically but loses original detail.
Lossless Compression: Compresses file without losing any data (e.g., Run-Length Encoding RLE, ZIP files).
Reversible, essential for text, executable code, and raw database files.

The Von Neumann Architecture introduces the concept of the Stored Program Computer, where both data
and instructions share the same memory space and system bus system.

KEY CPU REGISTERS
PC (Program Counter): Holds address of the next instruction to be fetched.
MAR (Memory Address Register): Holds memory location currently being read/written.
MDR (Memory Data Register): Holds data read from or written to memory.
ACC (Accumulator): Stores results of arithmetic and logic calculations from ALU.
CIR (Current Instruction Register): Stores instruction currently being decoded/executed.
The Fetch-Execute (F-E) Cycle
The fundamental operational loop of the CPU works in six distinct steps:
FIGURE 1.4 — SEQUENTIAL ORDER OF THE F-E CYCLE
1. The address contained in the PC is copied to the MAR.
2. The instruction is copied from the memory location in MAR and placed in MDR.
3. The value in the PC is incremented by 1.
4. The instruction is copied from the MDR and placed in the CIR.
5. The instruction is decoded.
6. The instruction is executed.
Interrupts & Peripheral Connections
An Interrupt is a signal sent from a device/software requesting CPU attention. When received, the CPU
suspends current execution to service the interrupt. Computers connect to external devices using
standardized ports:
USB (Universal Serial Bus): High-speed serial connection supporting plug-and-play peripherals.
HDMI / VGA: Video interface standards (HDMI transmits digital video+audio, VGA transmits legacy analogue video).
1.4 Operating Systems & Software Architecture
An Operating System (OS) provides a software platform hiding hardware complexity. Its core management
tasks include:
OS Task
Primary Responsibilities
Memory Management
Allocates RAM space to active processes, handles virtual memory paging.
Process Management
Schedules CPU time among running threads, avoids deadlock.
Hardware/Device Management
Communicates with hardware using low-level device drivers.
Security Management
Manages user authentication, file access permissions, and passwords.
Utility Software
Utilities perform specific maintenance tasks to keep a system optimized:
Disk Formatter: Prepares storage media for first use by wiping and initializing file systems. Virus Checker: Scans storage
for malware signatures. Defragmentation Software: Rearranges fragmented file clusters on HDDs sequentially for faster
read speed. Backup Utilities: Automatically copies critical system files (e.g., File History, Time Machine).

Two-Pass Assemblers & IDE Features
A Two-Pass Assembler scans code twice: Pass 1 builds a Symbol Table mapping labels to memory addresses;
Pass 2 converts mnemonics into opcode/operand binary values using the table.
An IDE (Integrated Development Environment) speeds up coding with tools: Auto-completion, Syntax
Highlighting, Integrated Debuggers (breakpoints/single-stepping), and Built-in Translators.

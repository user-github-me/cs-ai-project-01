# Chapter 1 — The Fundamentals

## Learning outcomes
- You will learn about:

- Binary magnitudes, binary prefixes, and decimal prefixes
- Binary, denary and hexadecimal number systems
- How to carry out binary addition and subtraction
- The use of hexadecimal and binary coded decimal (BCD) number systems
- Image resolution and color depth
- Representation of sound in a computer
- Effects of changing sampling rate and resolution on sound quality
- The need for file compression methods (such as lossy and lossless)
- The basic Von Neuman model of a computer system
- Understand source code vs machine code
- Difference between high-level and low-level languages
- Compilers and Interpreters
- Why computers need an operating system
- Fetch-Execute cycle
- Purpose and role of the registers PC, MDR, MAR, ACC,
- Key management tasks such as memory management, hardware management, security management, process management
- Need for utility software such as disk formatter, virus checker, defragmentation software, repair software, file compression and back-up software
- The need for these language translators: assemblers, compilers, interpeters
- benefits or drawback os using compilers or interpreters
- Features of a typical IDE
- Purpose of interrupts
- Connection of computers to peripheral devices such as USB, HDMI, VGA
- Relationship between assembly language and machine code
- different stages for a two-pass assembler
- tracing sample assembly language programming code
